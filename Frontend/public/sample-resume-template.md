# Sample Resume Template with Bookmarks

This is a reference for the Word bookmark format. Download the actual `.docx` file from the application.

## Instructions to Create Bookmarks in Word:

1. Open your resume in Microsoft Word
2. For each section, select the section title or placeholder text
3. Go to **Insert → Bookmark**
4. Enter the bookmark name exactly as shown below
5. Click **Add**

## Bookmark Names to Use:

```
{PROFESSIONAL_SUMMARY}      - 2-3 line summary of your professional background
{CORE_COMPETENCIES}         - Key technical and professional skills
{PROFESSIONAL_EXPERIENCE}   - Work experience and accomplishments
{EDUCATION}                 - Degrees, certifications, courses
{PROJECTS}                  - Notable projects and achievements
{CERTIFICATIONS}            - Professional certifications
{AWARDS}                    - Awards and recognitions
{LANGUAGES}                 - Languages you speak
```

## Tips:

- Use consistent bookmark names across your resume versions
- You can copy-paste these exact names into Word bookmarks
- Save your resume as `.docx` (Word format)
- After adding bookmarks, test detection in the app
